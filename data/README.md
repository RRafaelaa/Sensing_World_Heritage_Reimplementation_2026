# Shared data

These files are selected inputs and results for the three methods and the cross-method binary analysis. Generated intermediate files belong in `outputs/` or `data/outputs/`, not in this directory.

| Path | Role | Contents |
| --- | --- | --- |
| `extractions/complete_dataset.xlsx` | Final structured extraction | The `merged` sheet is the selected study-level table. Other sheets retain the Flash and targeted extractions, rule-based information, and metadata for comparison. |
| `extractions/Robustness_alignment_Hassan.xlsx` | Appendix C consistency check | Field-level and theme-level comparisons of two extracted records for the same Hassan, Zerva, and Aulet study, with a `Read me` sheet. |
| `geography/unesco_name_dictionary.json` | Processing input | UNESCO World Heritage property names and alternative names used by the matcher. |
| `geography/tentative_name_dictionary.json` | Processing input | Tentative List names and alternatives used by the matcher. |
| `geography/UNESCO_to_Map.xlsx` | Final mapping data | `Paper Status` contains paper-level matches and working columns. `To Map` contains 236 distinct papers selected for mapping, with site names and `City_Country_Pairs`. |
| `term_mapping/Binary_encodings.csv` | Cross-method result | Semicolon-delimited UTF-8 table of 464 paper records: an original index column, `filename`, 94 binary indicators for extracted terms, and 10 `Binary_Topic_*` indicators. |
| `topic_modeling/meta_data.csv` | BERTopic input | Bibliographic records with titles, abstracts, keywords, and stable identifiers. |
| `topic_modeling/comparison_report_sorted.csv` | Parameter-comparison result | Ranking of 192 BERTopic configurations from the historical comparison run. This ranking is distinct from the separate ten-random-seed stability check. |
| `topic_modeling/final_probability_distribution.xlsx` | Final BERTopic result | Document-level topic probabilities, a topic summary, low-confidence documents, and boundary documents. |
| `topic_modeling/seed_stability/` | Random-seed stability results | `seed_runs.csv` records per-seed metrics; `doc_assignments.csv` gives document-level topic assignments; `topic_matching.csv` matches topics to the reference run; `topic_stability_summary.csv` summarizes each reference topic. `README.md` documents the experiment settings and recorded environment. |

The three result workbooks include historical selection or review steps and are not identical to a fresh, fully automatic run of the scripts. In particular, the geography scripts produce candidate matches and `papers_unesco_status.csv`; the final selection in `UNESCO_to_Map.xlsx` is not encoded as a script here. `UNESCO_to_Map.xlsx` has UNESCO site names but no official site latitude/longitude columns. Geocoded latitude/longitude generated by the scripts describe place names extracted from papers.

For cross-file joins, `complete_dataset.xlsx` uses `filename` in its `merged` sheet, while `UNESCO_to_Map.xlsx` uses `paper` in `Paper Status` and `File_Name` without the `.txt` suffix in `To Map`. Confirm identifiers before combining rows. The exact source date of the included UNESCO dictionary snapshots is not recorded in this repository.

The published corpus contains 464 records, including two records with different titles that refer to the same Hassan, Zerva, and Aulet full-text study. The consistency workbook compares these two records; it is not the separate ten-paper manual accuracy check described in the manuscript.

The binary table combines term indicators derived from the extraction workbooks with topic assignments from BERTopic. See [src/term_mapping/README.md](../src/term_mapping/README.md) for the original notebooks, their intermediate CSV inputs, and the settings needed when working toward this result.
